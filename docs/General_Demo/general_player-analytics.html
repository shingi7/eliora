Individual Player Performance Dashboard

What this shows

  • Match‑by‑match timeline for a chosen player across any selected metric (e.g., xG, shots, pass accuracy). Lines reveal form trends, peaks, and dips.

How to use

  • Use the blue dropdown to change the player; use the yellow dropdown to change the metric. Hover to see match date and exact values. Compare recent trend vs long‑term baseline for selection and coaching.

Multi-Player Percentile Radar (2024)

What this shows

  • Squad comparison of players in 2024 on a percentile scale (0–100) for key metrics. Larger area indicates higher percentile (relative performance among teammates).

How to use

  • Toggle players in the legend to focus comparisons. Use outer vs inner positions to identify standout strengths and gaps across roles.

Team Leaders (Per‑90, Select Metric)

What this shows

  • Ranked bar chart of players for a chosen metric. Percentage metrics use averages; count metrics are normalized per‑90 to ensure fair comparison.

How to use

  • Use the dropdown to switch metrics. Scan the leftmost names to identify leaders; use this to support lineup decisions and incentive discussions.

Strengths & Weaknesses (Per Player)

What this shows

  • Top five strengths and top five weaknesses for the selected player based on z‑scores vs the 2024 squad distribution.

How to use

  • Use the dropdown to select a player. Prioritize training on the red bars (weakest z‑scores) and protect/nurture green strengths within role definitions.

Advanced ML: Similarity & Clustering

What this shows

  • PCA map of players (2024) colored by KMeans cluster (profile archetypes), and a nearest‑neighbor panel showing most similar players.

How to use

  • Use the nearest‑neighbor dropdown to choose a reference player and surface closest analogues for role fit, recruitment comparisons, or mentoring pairs.

Professional Notes

  • All visualizations include guardrails for missing/invalid values
  • Synthetic data distributions calibrated for realism (not random noise)
  • Ready to plug in real data sources with minimal code changes
