Quick Presets:

Radar Comparison

Compare selected players across chosen metrics. Z-scores show relative to the league average; raw values are unscaled.

Top Performers

Ranks players by a single metric within the selected seasons and minutes filter.

Holistic Score Bubble Chart

Bubble size = average z-score across selected composite metrics. Color indicates season when multiple seasons are selected.

Use X/Y to compare two metrics; labels show the top 10 by composite score.

Similarity

Similarity uses Euclidean distance across core z-score features within the filtered dataset, shown as a relative percentage (higher is more similar).

Best for finding stylistically similar profiles, not predicting outcomes.
